# HELIX

Welcome to the HELIX repository.

HELIX is an Organizational Engineering framework for designing, building, operating, and continuously improving AI-native organizations.

This repository contains the HELIX Specification, engineering standards, reference architectures, and the reference implementation (HELIX OS).
