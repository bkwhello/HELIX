Zero occurrences of `gtag(`, the literal string `'consent'`, `analytics_storage`, `ad_storage`, or `konnichiwa_consent` were found anywhere in this file.
  - The live GTM container (EV-026) contains zero references to `cmplz` or `konnichiwa_consent` — no bridge between the two systems was found configured there.
  - **Two independent, apparently unsynchronized consent-state mechanisms are present on the production site.**
- **Limitations:** no browser was executed, so it is not confirmed whether both banners can visually appear to the same visitor, in what sequence, or whether a real user's interaction with one system produces any observable effect on the other beyond what static code inspection can show. No authenticated GTM configuration inspection was performed. This finding is **evidence of absence** of a literal cross-reference, not definitive proof no bridge exists by any indirect mechanism.
- **Confidence:** High for "two separate storage/event mechanisms with no found literal cross-reference exist in the code inspected"; explicitly **not** a compliance or unlawful-processing determination — see verdict below.
