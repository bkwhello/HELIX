## B. Verification rule applied

Derived from observations/O-018.md–O-021.md (made explicit by O-021, Tests 4–5, and the 28 August 2026 segment of transformation/HV-IR-001.md, HV-INT-003): a core event is **Production Verified** when all three conditions hold:

1. the GTM configuration is present in the **published** container version, not only in the workspace read by GTM Preview;
2. behavioural evidence shows the trigger and tag firing correctly;
3. GA4 Realtime receives the event after a real production interaction **outside** GTM Preview.

"n/6" counts the six core events named in measurement/2026-W34-visibility-brief.md, Priority 3: `reservation_click`, `reservation_widget_open`, `phone_click`, `directions_click`, `private_dining_enquiry`, `catering_enquiry`. It counts events, not verification layers. It does not cover the wider event list in measurement/HV-MP-001.md.

## F. GA4 production receipt — 26 September 2026

*Source: GA4 Realtime screenshot, observed 26 September 2026.*

**Observation:** immediately after the outside-Preview submission, GA4 Realtime visibly showed `private_dining_enquiry` = **1**. The same view also showed `form_submit` = 1 and `form_start` = 1; these two values are recorded as visible values only, with no further meaning assigned.

**Interpretation boundary:** `private_dining_enquiry` = 1 is evidence that GA4 received the event within that Realtime window. It is not evidence of historical submission counts, structural exactly-once delivery, or long-term duplicate prevention — consistent with the Realtime caveats in observations/O-019.md and O-020.md.

## G. Inference

Condition 1 is met by section D; condition 2 by the inherited Preview evidence in section C; condition 3 by sections E–F. Because the required configuration is present in the published container and GA4 received the event while Preview was disconnected, the receipt was delivered through the published container — the distinguishing criterion established by observations/O-021.md, Tests 4–5. No condition of the rule remains missing.
