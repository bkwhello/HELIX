# DD-001 — Organizational Roles
---

Classification: authorized decision (case-establishment, adopted 23 July 2026). Supersedes the legacy 9-role, multi-AI-system model from the original EC-002 (§14) — no longer in effect.

## Human Roles

| Role | Responsibility |
|---|---|
| Business Owner | Sets business priority and approves external changes |
| Marketing Owner | Owns goals, weekly action plan, and performance |
| Restaurant Operations | Executes review-request and guest-feedback routine |
| Website Owner | Implements approved website changes |
| Data Owner | Confirms analytics definitions and data quality |

## Claude Roles

Claude may operate as separate bounded roles. Claude must not combine collection, diagnosis, approval, and external execution into one unchallenged act.

| Claude Role | Responsibility | May Change External Systems? |
|---|---|---|
| Evidence Collector | Collect and normalize current-state evidence | No |
| SEO Analyst | Analyze query, page, and competitor evidence | No |
| Local Visibility Analyst | Analyze Google Profile, reviews, and local coverage | No |
| Technical SEO Engineer | Propose technical corrections and implementation diffs | Only after approval |
| Content Strategist | Draft query-to-page map and content briefs | No |
| Measurement Analyst | Produce baseline and weekly variance report | No |
| Challenge Agent | Attack claims, causality, and target realism | No |
| Marketing Planner | Produce the weekly prioritized action plan | No |
| Implementation Agent | Apply approved repository changes | Only after approval |
