# DD-003 — Weekly Marketing Operating Loop
---

Classification: authorized decision (case-establishment, adopted 23 July 2026).

Run every Monday at 10:00 Europe/Amsterdam.

```text
Collect last 7 days
→ Compare with baseline and prior week
→ Identify material deviations
→ Test explanations against evidence
→ Challenge the diagnosis
→ Select maximum three priority actions
→ Request approval where required
→ Assign owner and deadline
→ Measure next cycle
```

## Weekly Output

Create `measurement/YYYY-Www-visibility-brief.md` (realizes WO-008) containing:

1. executive status
2. target-condition scorecard (see measurement/TC-register.md)
3. meaningful changes
4. evidence
5. diagnosis
6. maximum three priority actions
7. owner and due date
8. approval requirements
9. expected measurable effect
10. unresolved uncertainty

If goals are being achieved, the Marketing Capability maintains and compounds the gains. If growth stalls or declines, it must diagnose the condition before creating corrective actions.
