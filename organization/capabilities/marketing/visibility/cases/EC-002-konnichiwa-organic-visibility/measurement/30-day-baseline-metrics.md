# 30-Day Baseline Measurement Model
---

From the new case-establishment source, §11. This is a tactical subset of HV-MP-001's seven-layer model, scoped to the current 30-day execution window.

## Primary Outcome Metrics

| Metric | Definition |
|---|---|
| Local top-three coverage | % of defined Utrecht measurement points where Konnichiwa appears in the local top three for a target query |
| Organic top-three count | Number of target queries with a Konnichiwa page in positions 1–3 |
| Qualified organic sessions | Organic sessions landing on target commercial pages |
| Organic reservation actions | Reservation widget opens or confirmed reservation events attributable to organic/local traffic |
| Google Profile actions | Website clicks, reservation clicks, calls, route requests |

## Supporting Metrics

Impressions/clicks/CTR/average position by target query; indexed commercial pages; valid structured-data state; new Google reviews; review response time; referring local domains; mobile performance; landing-page conversion rate.

## Required Baseline Dimensions

Every measurement must preserve: query, landing page, channel, device, date range, geographic measurement point where applicable, branded vs. non-branded classification.

None of these metrics has data yet — see observations/O-001 through O-012 for collection status per metric.
