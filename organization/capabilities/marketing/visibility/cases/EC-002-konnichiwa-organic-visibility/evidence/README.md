## Evidence Requirements (from case-establishment, §10)

Acceptable evidence includes: Search Console exports; Google Business Profile performance exports; reproducible rank-grid or location-defined rank checks; website source and crawl output; PageSpeed Insights or equivalent test output; screenshots with date, query, and location; GA4 or consented analytics reports; Guestplan/reservation-click event data; public directory and platform records; documented implementation diffs; dated before-and-after measurements.

Unacceptable as sole evidence: a single personalized Google search; an AI-generated SEO score; an undocumented impression; an unverified competitor estimate; a ranking claim without query, location, device, and date; an assumption copied from the case-establishment document itself.
